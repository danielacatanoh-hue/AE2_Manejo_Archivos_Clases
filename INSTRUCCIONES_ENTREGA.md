# Qué debes hacer antes de entregar

1. Descarga manualmente un CSV y un JSON desde Hugging Face, como pide la guía de Canvas.
2. Guarda los archivos descargados en `datos/` como `datos_originales.csv` y `datos_originales.json` (conserva siempre los originales).
3. Actualiza `URL_CSV_ORIGEN` y `URL_JSON_ORIGEN` en `actividad_ae2.ipynb` con las URL exactas de los archivos que descargaste.
4. Adapta las columnas/campos de las modificaciones si los datasets elegidos tienen otros nombres.
5. Ejecuta todas las celdas en orden y comprueba las salidas.
6. Verifica que `resumen.txt` registre las URL y modificaciones reales.
7. Sube la carpeta a GitHub dentro de `AE2/` y registra varios commits descriptivos.

**Transparencia:** los archivos de `datos/` incluidos son datos de ejemplo para probar el código. No se afirma que sean copias descargadas de las URL indicadas. La descarga manual y la actualización de las URL son pasos necesarios para cumplir fielmente la consigna.
